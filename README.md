# 🎓 Student Management System

A **Java Swing-based Student Management System** developed as part of my Software Engineering coursework.

The system provides a graphical user interface (GUI) for managing student information, academic records, reports, and industry training eligibility.

## ✨ Features

* 👨‍🎓 **Student Management**

  * Add, update, and manage student information
  * View student details

* 📚 **Batch & Grade Management**

  * Manage student batches
  * Manage and record student grades

* 📊 **Report Management**

  * Manage and view student academic reports

* 🧮 **GPA Calculation**

  * Calculate student GPA based on academic grades

* 🆔 **Automatic Student ID Generation**

  * Automatically generate student IDs

* 🎓 **Industry Training Eligibility Checking**

  * Check student eligibility for industry training based on academic requirements
